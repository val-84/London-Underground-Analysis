# London-Underground-Analysis

# The aim of this analysis is to investigates the vulnerability of the London Underground network using spatial network analysis. The aim was to identify the most critical stations whose closure would cause major disruption to the network by analysing Degree Centrality, Betweenness Centrality, and Eigenvector Centrality weighted by passenger flows. The study also evaluated the impact of random and targeted station closures on overall network connectivity and resilience.
